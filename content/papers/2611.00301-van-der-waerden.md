## 1. Statements

```lean
def HasMonoAP (c : ℕ → Fin r) (N k : ℕ) : Prop :=
  ∃ a d, 0 < d ∧ a + (k - 1) * d ≤ N ∧ 1 ≤ a ∧ ∀ i < k, c (a + i * d) = c a

theorem W_3_3 : (∀ c : ℕ → Fin 3, HasMonoAP c 27 3) ∧ (∃ c : ℕ → Fin 3, ¬ HasMonoAP c 26 3)
theorem W_2_5 : (∀ c : ℕ → Fin 2, HasMonoAP c 178 5) ∧ (∃ c : ℕ → Fin 2, ¬ HasMonoAP c 177 5)
theorem W_2_6 : (∀ c : ℕ → Fin 2, HasMonoAP c 1132 6) ∧ (∃ c : ℕ → Fin 2, ¬ HasMonoAP c 1131 6)
```

## 2. Lower bounds

Each lower bound is witnessed by an explicit coloring, given as a bit string in the Lean development and checked by `decide`.
