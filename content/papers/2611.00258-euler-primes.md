## 1. Introduction

In 1772 Euler noticed that the polynomial $f(n) = n^2 + n + 41$ takes prime values for $n = 0, 1, \dots, 39$. This note explains that phenomenon and asks how long the prime-richness persists.

The main facts are formalized in Lean and listed on the abstract page. No one has yet declared they understand the formal statement of the prime count in §4, so its specification is unchecked.

## 2. The first forty values

The values $f(0), \dots, f(39)$ are $41, 43, 47, 53, 61, \dots, 1601$, and all of them are prime (result 2). The streak must end at $n = 40$, since
$$f(40) = 40^2 + 40 + 41 = 40 \cdot 41 + 41 = 41^2.$$
More generally, $41 \mid f(41k)$ and $41 \mid f(41k + 40)$ for every $k$, so no polynomial of this shape is prime for all $n$.

## 3. Why small primes never divide $f(n)$

Completing the square gives $4f(n) = (2n+1)^2 + 163$. For an odd prime $p$, $f$ has a root mod $p$ exactly when $-163$ is a square mod $p$. Also $f(n)$ is always odd, so $p = 2$ never divides it. Result 3 confirms by computation that $-163$ is a non-residue for every odd prime $p < 41$.

The reason behind this is a classical theorem of Rabinowitsch (1913): $n^2 + n + q$ is prime for all $0 \le n \le q - 2$ if and only if $\mathbb{Q}(\sqrt{1 - 4q})$ has class number one. For $q = 41$ this field is $\mathbb{Q}(\sqrt{-163})$, and $163$ is the largest Heegner number.

## 4. How often is $f(n)$ prime?

The Bateman–Horn conjecture predicts that the number of $n < x$ with $f(n)$ prime is approximately
$$\frac{C_f}{2} \operatorname{Li}(x), \qquad C_f = \prod_p \frac{1 - \omega_f(p)/p}{1 - 1/p},$$
where $\omega_f(p)$ is the number of roots of $f$ mod $p$. Because $\omega_f(p) = 0$ for every $p < 41$ (§3), the constant is unusually large: $C_f/2 \approx 3.32$.

For $x = 10^5$ this predicts about $3.32 \cdot \operatorname{Li}(10^5) \approx 31{,}970$ prime values. Result 4 gives exactly $31{,}985$, in close agreement. Note, though, that this comparison is only as trustworthy as the *specification* of result 4, which has not yet been reviewed.
